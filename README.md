# Exam Prep

Yeh project exam ki tayyari ke liye hai. Is mein sirf Markdown (`.md`) files hongi.

## Maqsad (Purpose)

- Har subject ke notes ek jagah organized rakhna
- Important topics, formulas aur definitions ka jaldi revision karna
- Practice questions aur unke jawab likhna
- Git ke zariye apni progress ka record rakhna

## Folder Structure

```
exam-prep/
├── README.md      # Yeh file — project ka taaruf
└── notes/         # Har subject ki alag .md file yahan rakhein
```

## Kaise Istemal Karein

1. `notes/` folder mein har subject ke liye nayi file banayein, jaise `notes/math.md`
2. Headings (`#`), bullet points (`-`) aur code blocks ka istemal karein
3. Kaam ke baad changes commit karein:

   ```
   git add .
   git commit -m "Math notes update"
   git push
   ```

## Qaida (Rule)

Is repo mein sirf Markdown files rakhi jayengi — koi code, PDF ya image nahi.
